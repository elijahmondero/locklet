# Locklet

Autonomous, no-camera **9:16 TikTok Live 3D Escape Room & Team Trap Race** powered by Three.js, KayKit CC0 3D models, WAL SQLite, and `tiktok-live-connector`.

## Features
- **2 Live Game Modes (`Co-op Vault + 10s Getaway Dash` & `Red vs. Blue Team Escape Race` + `Auto` rotation)**
- **4 Rotating 3D Room Themes** (`Sunken Treasury`, `Magma Forge`, `Haunted Study`, `Clockwork Vault`) with procedurally randomized wire, keypad PIN, and trap-bridge solutions every round
- **Mass Crowd + 1-at-a-Time Spotlight:** Everyone searches props, pumps back rising hazards with screen taps, and feeds clues to the 5-slot On-Deck Spotlight queue
- **Balanced Gift Loop:** UV Clue Light (`5💎`), Cut the Line (`10💎`), 1-Hit Rubber Shield + Pump (`15💎`), and Blackout Sabotage / 2x Cursed Pot (`25💎`)
- **Direct On-Screen Play Bar:** Interactive chat box & 1-tap controls right inside the 9:16 screen

## Quick Start
```bash
npm install
npm run start:server
npm run dev
```
